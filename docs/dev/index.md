## 一句话概括

网页端仓库是**唯一数据权威源**；后端 `csh-api` 提供提交、反馈、签名、下载票据与公告等动态能力；两个桌面端是**外壳客户端**，均通过 GitHub 公开仓库直读软件数据，安装包不含软件清单（Win7 版仅内置镜像站清单与图标）。

## 仓库一览

| 仓库 | 角色 | 主要语言 / 框架 | 发布物 |
| --- | --- | --- | --- |
| `ClassSoftwareHub` | 网站与软件数据权威源 | Vue 3 + Vite + TypeScript | 静态站点（另有单文件 HTML 构建可选） |
| `csh-api` | 后端 | JavaScript（EdgeOne Pages Functions） | 边缘函数（自动部署） |
| `ClassSoftwareHub-Desktop` | Win10 桌面端 | C# / WinUI 3 / .NET 10 | Inno Setup 安装包 |
| `ClassSoftwareHub-windows7` | Win7 兼容桌面端 | C# / Avalonia / .NET 6 | 安装包、便携版 zip |

## 已确认与待确认

**已确认**：四仓职责与数据流、网页端路由与 12 个内置工具、Win10 与 Win7 的版本号规则与更新双通道、两版安装脚本的系统门槛与进程处理策略、日志与缓存目录、后端 EdgeOne 路由与环境变量、OSS 直传 / 票据下载 / 加速签名协议、age 公钥加密联系方式。

**待确认 / 已知遗留**：

| 项 | 说明 |
| --- | --- |
| 客户端迁移到新后端 | 网页端源码已切到 `api.classsoftwarehub.cn`；两个桌面端的提交入口仍留有旧域常量，需在后续版本切换 |
| 访问统计服务 | 旧统计服务 `service.132614.xyz` 仍在用；是否并入 `csh-api` 待定 |
| Authenticode 签名 | 两个安装脚本均未配置签名工具，当前依赖 `.md5` 校验；是否引入待确认 |
| 站点内容清单 | `content/manifest.json` 作为备用同步来源尚未正式发布 |
