## 一句话概括

网页端仓库是**唯一数据权威源**；两个桌面端是**外壳客户端**，均通过 GitHub 公开仓库直读网页端的软件数据，安装包不自带内容包。

## 已确认与待确认

**已确认**：三仓数据流关系、网页端 8 条路由与 11 个内置工具、Windows 7 版的版本号规则与更新双通道、安装脚本的系统门槛与进程处理策略、日志与缓存的目录结构、提交服务三条路由与 OSS 直传/票据下载协议、age 公钥加密联系方式、CI/CD 五个工作流的职责分工。

**待确认**：

| 项 | 说明 |
| --- | --- |
| `ClassSoftwareHub-Desktop` 仓库实现 | 本地未定位到该仓库，主进程/渲染进程划分、IPC、自动更新、打包与签名细节待确认 |

本文档中的命令、路径、端口、环境变量、接口与配置项均来自仓库文件或脚本。关键结论附代码依据，格式为 `相对路径/文件名:行号` 或 `相对路径/文件名`。无法从代码确认的信息统一标注「待确认」。
