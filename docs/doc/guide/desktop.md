> **快速上手** - 两个桌面端的共同行为：安装、首次启动、更新与卸载

本章适用于 WinUI 3 桌面版（Windows 10）与 Windows 7 兼容版。两者共享同一套软件数据、更新协议与数据目录布局，差异集中在系统要求、安装包命名与视觉实现：

| 版本 | 系统要求 | 安装包 | 详细说明 |
| --- | --- | --- | --- |
| 桌面端（Win10） | Windows 10 1809+（x64） | `ClassSoftwareHub-Setup-dv<版本>.exe` | [Windows 10 使用说明](./win10.md) |
| Windows 7 兼容版 | Windows 7 SP1+（x64） | `ClassSoftwareHub-Setup-win7-dv<版本>.exe` / `ClassSoftwareHub-Portable-win7-dv<版本>.zip` | [Windows 7 版本使用说明](./win7.md) |

## 安装

### 安装版

1. 从[下载页面](/download)获取对应系统的安装包。
2. 双击运行。安装前若检测到应用正在运行，安装程序会先礼貌关闭进程，不退再强杀；应用无未保存状态，设置即时落盘，被杀不丢数据。
3. 按向导完成安装，可选创建桌面快捷方式。
4. 安装完成自动拉起应用。

两个版本均为**当前用户安装**，默认目录分别是：

- Win10：`%LOCALAPPDATA%\Programs\ClassSoftwareHub`
- Win7：`%LOCALAPPDATA%\Programs\ClassSoftwareHub-Win7`

### 便携版（仅 Windows 7 兼容版）

1. 获取 `ClassSoftwareHub-Portable-win7-dv<版本>.zip`。
2. 解压到任意位置（U 盘亦可）。
3. 双击根目录的 `ClassSoftwareHub.exe` 启动。
4. `app` 文件夹必须与启动器放在一起，单独拿走 exe 无法启动。

::: warning 校验安装包
每个安装包均附带同名 `.md5` 文件，下载后请校验完整性。
:::

## 首次启动

1. 启动后进入主界面，展示站点简介与快速入口。
2. **首次启动必须联网**：安装包不自带软件数据，软件清单需从 GitHub 仓库同步；未取到时界面显示「尚未获取到内容」并给出重试入口。Win7 版随包附带的只有系统镜像站清单与图标，不含软件清单。
3. 同步完成后即可浏览软件、使用工具。后续启动只在上游数据变化时增量同步。

## 登录

桌面端**无账号登录**。所有需要身份的操作（提交软件、回声洞投稿、反馈中心）均为匿名提交，由维护者在后台处理。

## 共同功能

| 功能 | 说明 |
| --- | --- |
| 软件下载 | 与网页端一致的分类浏览、详情查看、下载与校验值；清单跟随网站数据自动更新 |
| 全站搜索 | 一次搜索软件、内置工具与页面 |
| 内置工具 | 抽号、计时、时钟、编码、图片取色、函数图像、化学、系统工具等 |
| 工具侧边栏 / 浮窗 | 把常用工具放到屏幕边缘或独立浮窗，可置顶、可贴边 |
| 截屏贴图 | 框选屏幕区域后编辑、复制、存盘与钉图 |
| 外观 | 浅色 / 深色主题；背景材质按系统能力分级降级 |
| 自动更新 | 双通道（正式版 / 预览版），自动核对版本、下载并校验安装包 |
| 更新日志 | 站内直接查看历史版本说明 |
| 数据容错 | 单条数据异常不影响整站，页面顶部给出明确提示 |

各版本的工具数量与系统集成能力不同：Win10 版提供 10 个课堂 / 系统工具及 Hub AI、开机启动项、系统修复、应用卸载与 AppData 管理等页面；Win7 版提供 13 个工具，其中包含 Win10 版没有的桌面留言、教室喊话与系统镜像下载。详见各版本说明。

## 数据存储位置

| 内容 | 位置 |
| --- | --- |
| 设置、缓存、内容（数据根目录） | `%LOCALAPPDATA%\ClassSoftwareHub\` |
| 同步下来的软件数据 | `%LOCALAPPDATA%\ClassSoftwareHub\content\` |
| 日志 | `%LOCALAPPDATA%\ClassSoftwareHub\logs\{启动时间}\`，每次启动一个目录 |
| WebView2 用户数据 | `%LOCALAPPDATA%\ClassSoftwareHub\WebView2\` |
| 便携版排障日志 | 便携版目录旁的 `port.log` |

两个版本共用同一数据根目录。若同机安装两版，设置、内容缓存与日志会共用；安装目录与安装标识不同，程序本体互不覆盖。

## 更新

1. 在设置页选择更新通道：正式版（stable）或预览版（insider）。
2. 点击「检查更新」。客户端读取**本版本自己的仓库** Release：正式版取非预发布的最新版，预览版取预发布及非预发布。
3. 发现新版本后下载安装包并校验：优先使用同名 `.md5` 资产，其次使用 GitHub API 返回的 SHA256。Win7 版在发布方未提供任何校验值时会中止更新、不运行未校验的安装包；Win10 版当前会记录警告后继续安装，建议尽量使用带校验值的发布。
4. 安装过程为静默安装，许可页会被跳过并视为已接受，升级流程不被打断。
5. Windows 7 安装版采用「启动器 + `app\` 子目录」两层结构，更新只替换 `app\` 内的程序文件，桌面快捷方式指向的启动器路径保持有效；Win10 版为单层安装，原地覆盖。

### 回滚

设置页可查看历史版本列表（正式版通道只列正式版，预览版通道同时列出预览版），选择任意版本安装，不校验版本高低。

### 便携版更新（仅 Win7）

便携版不会自动替换自己（正在运行的程序无法覆盖自身）。有新版本时，请到发布页下载新的便携包，解压后**替换整个 `app` 文件夹**；存放在 `%LOCALAPPDATA%\ClassSoftwareHub` 的设置不会丢失。

## 卸载

**安装版**：通过「设置 → 应用 → 已安装的应用」或控制面板的卸载项执行。卸载不会删除 `%LOCALAPPDATA%\ClassSoftwareHub` 中的设置、缓存与日志；如需彻底清除，请手动删除该目录。Win10 版还提供应用内「卸载残留清理」。

**便携版**：直接删除解压目录即可。该形态不经安装程序，不写卸载注册表项；设置与缓存仍保存在 `%LOCALAPPDATA%\ClassSoftwareHub`。

## 故障排查

| 现象 | 原因 | 处理方式 |
| --- | --- | --- |
| 双击桌面图标无反应，多次点击仍无界面 | 关闭窗口默认是收进托盘，进程未退出；第二个实例被单实例互斥体拦下 | 第二个实例会通过命名事件唤醒第一个实例并显示主窗口。若仍无反应，查看托盘区（含溢出区）是否有应用图标 |
| 进程留在任务管理器中，托盘菜单「退出」无效 | 工具浮窗等窗口拦截了关闭事件 | 已通过「应用正在退出」全局标记修复；如复现，请在任务管理器结束进程并反馈 |
| 软件列表为空，提示「尚未获取到内容」 | 首次启动未联网，或 GitHub 访问不通 | 连接网络后点击重试；若持续失败，检查网络能否访问 `github.com` |
| 详情页内打开官网无反应 | 未安装 WebView2 运行时 | 安装 WebView2 运行时；Windows 7 上最高仅支持 109.x 版本 |
| 主界面无法显示（Win7） | 极少数老显卡 D3D11 与 OpenGL 均不可用 | 以 `--software-render` 参数启动；若旧实例卡住，可加 `--takeover` 一并接管 |
| 界面点不动或托盘无图标（Win7） | 走了非预期的系统版本分支 | 便携版目录旁的 `port.log` 与 `%LOCALAPPDATA%\ClassSoftwareHub\logs\` 下的日志可定位；反馈时请附带 |

更多按版本拆分的问题见[常见问题](./faq.md)与[故障排查](./troubleshooting.md)。
