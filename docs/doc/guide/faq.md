## 网页端

### 页面顶部出现红色提示条

- **现象**：页面顶部显示「有 N 个数据文件未读取」，并列出文件名与大致行号。
- **原因**：某个软件 JSON 格式错误。
- **处理方式**：该文件被跳过，其余软件正常显示。修正对应文件的 JSON 语法后刷新即可。若为访客，请将文件名与行号反馈给维护者。

### 详情页显示「未找到该软件」

- **现象**：打开详情页提示未找到该软件。
- **原因**：历史数据中曾有 `id` 混入 `?` `&` `=` 等参数符号，导致路由解析失败。
- **处理方式**：该问题已修复；如仍出现，请反馈具体地址。

### 点击「下载」没有反应

- **现象**：点击下载按钮后没有开始下载。
- **原因**：该下载项是官网下载页或网盘，按钮文字分别为「前往官网」「前往网盘」。
- **处理方式**：查看按钮文字与说明。真正的文件直链按钮文字为「下载」。

### 加速链接提示过期或 403

- **现象**：点开自建加速链接提示过期、签名无效或无权限。
- **原因**：自建加速链接约 15 分钟有效；签名还受 Referer 白名单与每日配额限制。
- **处理方式**：刷新页面重新获取链接；仍失败时在来源下拉中改用公共镜像或 GitHub 原始地址。

### 提交时提示额度用尽

- **现象**：提交软件或反馈时提示今日次数已达上限。
- **原因**：后端按设备限制投稿频率（默认每日 6 次、最多 3 条待审核）。
- **处理方式**：次日再试；紧急问题可先在 GitHub Issue 反馈。

### 后端不可用

- **现象**：提交、公告、OSS 下载等功能报错，但软件列表正常。
- **原因**：EdgeOne 后端或 OSS 临时异常。
- **处理方式**：打开 `https://api.classsoftwarehub.cn/` 查看状态面板；静态浏览与 GitHub 下载不受影响。

### 图片图标无法显示

- **现象**：软件卡片显示首字母占位而非图标。
- **原因**：数据中 `icon` 留空，或图片 URL 加载失败。
- **处理方式**：不影响下载。可向维护者反馈补充图标。

### 商店链接变成死循环

- **现象**：点击商店链接后，商店提示先去商店里装商店。
- **原因**：本机没有「应用商店」（LTSC / 精简版 / 被卸载过）。
- **处理方式**：按 `Win + R` 输入 `wsreset -i` 让 Windows 联网装回商店；备用命令 `winget install 9WZDNCRFJBMP`。

### 备用站打不开

- **现象**：备用站点无法访问。
- **原因**：区域性网络问题。
- **处理方式**：改用主站。

## 桌面端（通用）

### 双击桌面图标无反应

- **现象**：关闭窗口后再点桌面图标，多次点击仍无界面。
- **原因**：关闭窗口默认是收进托盘，进程并未退出；第二个实例被单实例互斥体拦下。
- **处理方式**：第二个实例会通过命名事件唤醒第一个实例并显示主窗口。若仍无反应，查看托盘区（含溢出区）是否有应用图标；Win7 版可加 `--takeover` 启动。

### 软件列表为空

- **现象**：首次启动后软件列表为空，提示「尚未获取到内容」。
- **原因**：首次启动未联网，或 GitHub 访问不通。安装包不自带软件数据（Win7 版只附带镜像站清单与图标）。
- **处理方式**：连接网络后点击重试；若持续失败，检查网络能否访问 `github.com` 与 `raw.githubusercontent.com`。

### 详情页内打开官网无反应

- **现象**：在软件详情页点击「打开官网」没有反应。
- **原因**：未安装 WebView2 运行时。
- **处理方式**：安装 WebView2 运行时。Windows 7 上最高仅支持 109.x。

### 更新校验失败

- **现象**：更新下载完成后提示校验不通过。
- **原因**：下载不完整、代理改写内容，或发布资产本身异常。
- **处理方式**：重新下载；若持续失败，到发布页手动下载并核对 `.md5`，或按 GitHub API 返回的 SHA256 校验。

### AI 助手无法连接

- **现象**：Hub AI 发送消息报网络错误或 401。
- **原因**：API 地址、模型名或密钥不正确；或本机无法访问该服务商。
- **处理方式**：在 AI 设置页核对服务商、Base URL、模型与密钥；本地模型需先启动 Ollama / LM Studio。密钥仅保存在本机（DPAPI 加密）。

## Windows 10 桌面端

### 安装时提示系统版本过低

- **现象**：安装程序拒绝安装。
- **原因**：系统低于 Windows 10 1809（build 17763）。
- **处理方式**：升级系统，或改用 Windows 7 兼容版 / 网页端。

### 界面卡顿或花屏

- **现象**：滚动、动画卡顿，偶发花屏。
- **原因**：显卡驱动异常或硬件加速不可用。
- **处理方式**：更新显卡驱动；仍异常时附带日志反馈。

### 下载速度慢

- **现象**：大文件下载速度明显低于带宽。
- **原因**：自建加速不可用，已回退公共镜像或 GitHub；或源站限速。
- **处理方式**：稍后重试；自建加速按 IP 有限额，繁忙时会自动回退。

## Windows 7 兼容版

### 界面出现随机灰矩形残影

- **现象**：抽号页等动画密集页面出现位置随机的浅灰矩形残影。
- **原因**：Windows 7 老显卡的表面保帧不可靠。
- **处理方式**：本版默认已启用软件渲染；如仍出现，尝试加 `--software-render` 参数启动。

### 主界面无法显示

- **现象**：启动后看不到主界面。
- **原因**：极少数老显卡 D3D11 与 OpenGL 均不可用。
- **处理方式**：以 `--software-render` 参数启动；若旧实例卡住，可加 `--takeover` 一并接管。

### WebView2 装不上

- **现象**：安装 WebView2 运行时失败。
- **原因**：Windows 7 上运行时止于 109.0.1518.x，官方引导程序拉取的是更新版本。
- **处理方式**：手动安装 109.x 离线包；不安装也不影响主要功能，网页浮层会降级为外部浏览器打开。

## 开发与维护

### 文件回退或丢失

- **现象**：本地修改的数据文件回退或丢失。
- **原因**：项目位于 OneDrive 等同步目录下，可能发生同步冲突。
- **处理方式**：对照上游重新应用修改。建议将工作副本移出同步目录。

### 组件库升级后图片图标失效

- **现象**：升级 WinUIonWeb 后导航项的图片图标不再显示。
- **原因**：`WinNavigationView` 相对上游补充了「图片图标」支持，升级后需重新应用该补丁。
- **处理方式**：重新应用补丁后重新构建。
