> 按「现象 — 原因 — 处理方式」组织，覆盖网页端与桌面端高频问题

## 网页端

### 页面顶部出现红色提示条

- **现象**：页面顶部显示「有 N 个数据文件未读取」，并列出文件名与大致行号。
- **原因**：某个软件 JSON 格式错误。
- **处理方式**：该文件被跳过，其余软件正常显示，不会导致整站无法打开。修正对应文件的 JSON 语法后保存刷新，提示条自动消失。若为访客，请将提示中的文件名与行号反馈给维护者。

### 详情页显示「未找到该软件」

- **现象**：打开详情页提示未找到该软件。
- **原因**：历史数据中有 5 个 `id` 混入了 `?` `&` `=` 等参数符号，导致路由解析失败。
- **处理方式**：该问题已修复（修正为 `7-zip`、`9wzdncrfjbmp`、`xpfp7f8rl7mb1w`、`xpddvc6xtqqkmm`、`dism-gui`）；如仍出现，请反馈具体地址。

### 点击「下载」没有反应

- **现象**：点击下载按钮后没有开始下载。
- **原因**：该下载项是官网下载页或网盘，按钮文字分别为「前往官网」「前往网盘」，需在新标签页中继续操作。
- **处理方式**：查看按钮文字与说明。真正的文件直链按钮文字为「下载」，点击后在本页直接开始下载。

### 文字溢出卡片

- **现象**：详情页下载项卡片中的文字溢出边界。
- **原因**：校验值整串写入了 `note` 字段。128 位哈希没有可断行的地方，会导致文字溢出。
- **处理方式**：将哈希移至 `hash` 字段，`note` 只保留说明文字。

### 图片图标无法显示

- **现象**：软件卡片显示首字母占位而非图标。
- **原因**：数据中 `icon` 留空，或图片 URL 加载失败。
- **处理方式**：不影响下载。可向维护者反馈补充图标；分类图标仍使用字形。

### 商店链接变成死循环

- **现象**：点击商店链接后，商店提示先去商店里装商店。
- **原因**：本机没有「应用商店」（LTSC / 精简版 / 被卸载过）。
- **处理方式**：详情页对「只有商店这一个入口」的软件会自动补一行说明：按 `Win + R` 输入 `wsreset -i` 让 Windows 联网装回商店，备用命令 `winget install 9WZDNCRFJBMP`。该说明由前端自动出现，无需在数据中做任何事。

### 备用站打不开

- **现象**：备用站点无法访问。
- **原因**：区域性网络问题（福建闽北、闽西地区可能遇到）。
- **处理方式**：改用主站。

## 桌面端

### 双击桌面图标无反应

- **现象**：关闭窗口后再点桌面图标，多次点击仍无界面。
- **原因**：关闭窗口默认是收进托盘，进程并未退出；第二个实例被单实例互斥体拦下。
- **处理方式**：已修复：第二个实例会通过命名事件唤醒第一个实例并显示主窗口。若仍无反应，查看托盘区（含溢出区）是否有应用图标。

### 托盘菜单「退出」无效

- **现象**：主窗关了、托盘图标摘了，进程却一直留在任务管理器中。
- **原因**：工具浮窗等窗口把关闭事件拦下来当「收起来」用，导致退出流程被中止。
- **处理方式**：已通过「应用正在退出」全局标记修复。如复现，请在任务管理器结束进程并反馈。

### 软件列表为空

- **现象**：首次启动后软件列表为空，提示「尚未获取到内容」。
- **原因**：首次启动未联网，或 GitHub 访问不通。安装包不自带内容包，必须联网同步。
- **处理方式**：连接网络后点击重试；若持续失败，检查网络能否访问 `github.com`。

### 详情页内打开官网无反应

- **现象**：在软件详情页点击「打开官网」没有反应。
- **原因**：未安装 WebView2 运行时。
- **处理方式**：安装 WebView2 运行时。Windows 7 上最高仅支持 109.x 版本，装不上是正常的。

### 界面出现随机灰矩形残影

- **现象**：抽号页等动画密集页面出现位置随机的浅灰矩形残影，每帧形状不同。
- **原因**：Windows 7 老显卡的表面保帧不可靠，局部重绘时未重绘区域露出残留像素。
- **处理方式**：Windows 7 上默认已启用软件渲染，该问题从机制上不可能出现。如仍出现，尝试加 `--software-render` 参数启动。

### 主界面无法显示

- **现象**：启动后看不到主界面。
- **原因**：极少数老显卡 D3D11 与 OpenGL 均不可用，自动降级链也救不回来。
- **处理方式**：以 `--software-render` 参数启动；或使用 `--takeover` 结束异常实例。

### 文件回退或丢失

- **现象**：本地修改的数据文件回退或丢失。
- **原因**：项目位于 OneDrive 等同步目录下，可能发生同步冲突。
- **处理方式**：对照上游重新应用修改。建议将工作副本移出同步目录。

### 组件库升级后图片图标失效

- **现象**：升级 WinUIonWeb 后导航项的图片图标不再显示。
- **原因**：`WinNavigationView` 相对上游补充了「图片图标」支持，升级后需重新应用该补丁。
- **处理方式**：重新应用补丁后重新构建。
