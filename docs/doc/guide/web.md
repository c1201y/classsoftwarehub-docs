> **快速上手** - 无需安装、无需登录，打开浏览器即可使用

## 访问方式

| 入口 | 地址 |
| --- | --- |
| 主站 | `https://classsoftwarehub.cn` |
| 备用站点 | `https://classsoftwarehub.132614.xyz`|

网页端为纯静态站点，**无需注册账号**即可浏览与下载。亦可以使用 `npm run build:single`命令，在本地生成约 2 MB 的单文件 HTML 供离线打开；线上部署使用的是多文件构建。

## 登录与账号

网页端**不提供账号体系**，无登录环节。涉及身份的功能通过以下方式实现：

1. **提交软件、回声洞投稿、反馈中心**：填写内容后直接提交，无需 GitHub 账号；提交进入审核队列，由维护者在 GitHub Issue 上处理。
2. **联系方式加密**：「提交软件」与「反馈中心」的联系方式字段在浏览器本地用 age 公钥加密后再提交，公开记录中仅为密文，仅维护者可用私钥解密。

## 后端服务

网页端的动态能力由自建后端提供，地址为 `https://api.classsoftwarehub.cn`（腾讯 EdgeOne Pages Functions，源码仓库 `c1201y/csh-api`）。它负责：

- 接收软件提交、回声洞投稿与反馈，写入仓库草稿并转成审核 Issue
- 为 OSS 直传签发短时凭证，为私有桶文件签发下载票据
- 为 GitHub 文件签发自建加速链接
- 提供站点状态、公告、下载统计与维护清理接口

浏览与下载不依赖账号；后端不可用时，静态页面仍可打开，动态功能会给出明确错误提示。

## 典型操作流程

### 下载一个软件

1. 打开站点，首页按分类或平台浏览，也可在搜索面板输入软件名称。
2. 点击卡片进入详情页（地址形如 `#/download/7-zip`）。
3. 核对版本号、系统限制与体积。
4. 在下载区选择对应平台的条目：
   - 按钮文字为「下载」→ 本页直接开始下载；
   - 按钮文字为「前往官网」→ 新标签页打开厂商下载页；
   - 按钮文字为「前往网盘」→ 新标签页打开分享页。
5. 如需校验完整性，点击校验值复制完整哈希，与下载到的文件自行比对。

### 使用课堂抽号工具

1. 通过搜索面板或底部导航进入「内置工具」，选择「随机抽号」。
2. 输入号码范围（例如学号 1~50）。
3. 按需设置一次抽取数量、是否抽过不重复、是否按号码随机分组。
4. 开始抽取。

### 提交一个软件

1. 进入「提交软件」页（`#/submit`）。
2. 可直接填写，或使用「从 GitHub 一键读取」自动填充仓库信息。
3. 填写必填项：`id`、`name`、`category`、`tagline`、`description`、`system`、联系方式，以及至少一条下载项（文件直链、官网下载页或网盘页均可）。
4. 可选填写校验值，支持带 `MD5:` 前缀或按字节分隔的写法。
5. 提交后进入审核队列；维护者在 Issue 上标注 `approved` 后合并发布。

每设备每日最多提交 6 次、最多 3 条待审核；联系方式可用 age 公钥加密。

## 权限说明

| 角色 | 可执行的操作 |
| --- | --- |
| 访客 | 浏览、搜索、下载、使用全部内置工具、提交软件、回声洞投稿、提交反馈 |
| 维护者 | 合并或驳回提交、编辑软件数据与站点文字、修改 CI 配置、管理后端环境变量 |

网页端不存在用户级服务端鉴权；「提交」由后端校验后写入公开仓库草稿或创建 Issue。清理、文件登记、下载统计等管理接口需 `X-Purge-Token`；状态与公告接口公开。

## 常见问题

| 现象 | 原因 | 处理方式 |
| --- | --- | --- |
| 页面顶部出现红色提示条 | 某个软件 JSON 格式错误 | 该文件被跳过，其余软件正常显示。将提示中的文件名与行号反馈给维护者修正 |
| 点击「下载」没有反应 | 该下载项是官网下载页或网盘，按钮文字分别为「前往官网」「前往网盘」 | 查看按钮文字与说明 |
| 图标显示为首字母占位 | 该软件 `icon` 为空或图片加载失败 | 不影响下载；可向维护者反馈补充图标 |
| 加速链接提示已过期 | 自建签名链接约 15 分钟有效 | 刷新页面重新下载 |
| 提交时提示额度用尽 | 每设备每日 6 次、最多 3 条待审核 | 次日再试，或先在 GitHub Issue 反馈 |
| 备用站打不开 | 区域性网络问题 | 改用主站 |

后端自身状态可在 `https://api.classsoftwarehub.cn/` 查看。
