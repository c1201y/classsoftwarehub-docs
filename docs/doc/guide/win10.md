> **WinUI 3 原版** - 面向 Windows 10 1809 及以上，完整功能与系统集成

## 安装前提

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 1809（build 17763）及以上，x64 |
| .NET 运行时 | **无需单独安装**。应用为自包含发布 |
| WebView2 运行时 | 可选。仅「应用内网页浮层」需要；安装程序会尝试引导安装 |
| 磁盘空间 | 安装版默认装入 `%LOCALAPPDATA%\Programs\ClassSoftwareHub` |

安装包文件名形如 `ClassSoftwareHub-Setup-dv<版本>.exe`。安装程序在启动时自行判断系统版本：低于 Windows 10 1809 时拒绝安装，并提示改用 Windows 7 兼容版或网页版。安装为**当前用户级**（`PrivilegesRequired=lowest`），不需要管理员权限。

## 安装与卸载

### 安装

1. 从[下载页面](/download)获取 Win10 安装包。
2. 双击运行。若检测到应用正在运行，安装程序会先请求关闭，确认后礼貌结束进程，不退再强制结束。
3. 按向导完成安装，可选创建桌面快捷方式。
4. 安装完成自动拉起应用。

::: warning 校验安装包
每个安装包均附带同名 `.md5` 文件，下载后请校验完整性。客户端更新时会优先按 `.md5`、其次按 GitHub API 的 SHA256 校验，校验不通过不会执行安装包；未提供任何校验值的发布当前会记录警告后继续安装。
:::

### 卸载

通过「设置 → 应用 → 已安装的应用」或控制面板卸载。卸载项显示名形如 `ClassSoftwareHub dv<版本>`。

卸载**不会删除** `%LOCALAPPDATA%\ClassSoftwareHub` 中的设置、缓存与日志；如需彻底清除，请在卸载后手动删除该目录，或在卸载前使用应用内「应用卸载」页的残留清理。

## 首次启动

新装后首次启动进入分步配置向导，共十二步：欢迎、外观、下载、截图、屏幕边缘侧边栏、侧边栏位置、侧边栏大小、Hub AI、更新、开机启动、条款、完成。外观主题、下载位置、常用功能与 Hub AI 相关选项在向导内一次选定，不必装完再逐项查找。向导走完后才显示主界面。

首次启动必须联网：

1. 安装包**不自带软件数据**，启动后从 GitHub 公开仓库同步软件清单。
2. 未取到时界面显示「尚未获取到内容」并提供重试入口。
3. 同步完成后即可浏览软件、使用工具。后续启动只在上游 commit 变化时增量同步。

桌面端**无账号登录**。提交软件、回声洞投稿、反馈中心均为匿名提交，由维护者在后台处理。

## 主要功能

### 软件与下载

| 功能 | 说明 |
| --- | --- |
| 分类浏览 | 按用途分类展示软件卡片，磁贴与网格两种视图，支持全站搜索 |
| 软件详情 | 版本、体积、系统限制、官网、仓库、开发者与开源协议、逐平台下载项与校验值 |
| 下载 | 文件直链、官网页面、网盘、应用商店四类入口 |
| 多线程下载 | ≥ 8 MB 的文件自动分片，最多 8 路并行、每段 3 次重试；不支持跨重启续传 |
| GitHub 加速 | 设置中可选「自动 / 自建加速 / GitHub 源」；自动模式并行测速排序并缓存 8 分钟，自建加速取不到签名时回退公益镜像与原始地址 |
| 下载管理 | 进行中 / 已完成列表、速度与进度、取消与重试，统一在「任务进行」中查看；关闭浮层不会中断任务 |
| 安装或解压 | 下载完成后可直接启动安装程序，或解压到指定位置 |

### 导航与搜索

- 顶栏搜索框按 `Ctrl+K` 唤起，一次检索软件、内置工具与页面。
- 首页顶部可显示应用内公告，用于通知全体用户的事项。
- 本版新增的入口在导航栏标注 **New**，仍在打磨的标注 **Beta**，显示三天后自动消失，更换版本后重新计时。

### 内置工具（共 18 个）

| 分组 | 工具 |
| --- | --- |
| 课堂工具 | 随机抽号、课堂计时器（倒计时 / 秒表）、全屏时钟、方程求解、化学方程式配平 |
| 系统工具 | 图片取色、编码 / 哈希、自动关机、磁盘空间、白板专杀、AppData 管理、系统修复、PowerPoint 触控优化、虚拟内存、幽灵文件清理、系统功能、系统优化 |
| 单独入口 | 函数图像 |

函数图像支持显函数、隐函数、不等式、极坐标与参数方程，可作点、线段、圆、椭圆、双曲线与多边形，并能绘制平行线、垂线与切线。

::: tip 自定义导航栏
默认放在一级导航的页面（教室喊话、查阅单词、文档库、PowerPoint 触控优化）与上述工具，都可以在「设置 → 自定义导航栏」中重新安排：常用页面单独提到一级，其余收进「课堂工具 / 系统工具」。首页、软件下载、Hub AI、侧边布局、函数图像固定在一级，不参与调整。
:::

### 学习与文档

| 功能 | 说明 |
| --- | --- |
| 查阅单词 | 内置约三万条常用词，未收录的词转在线词典查询；支持英汉互译与整句翻译，另有不离开当前界面的快速查词浮窗 |
| 文档库 | 收录电脑优化与使用技巧的图文教程，支持按标题、简介与标签检索，可读 Markdown、纯文本与 Word 文档 |
| 教室喊话 | 向同一配对码的设备发送一条通知，显示 180 秒后自动消失；接收方设备上运行本应用即可收到 |

文档库的文章随站点更新，不必等待版本发布。

### Hub AI

内置 AI 助手页，支持多家服务商：

| 服务商 | 默认接入地址 |
| --- | --- |
| DeepSeek（默认） | `https://api.deepseek.com/v1` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| Kimi | `https://api.moonshot.cn/v1` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |
| MiniMax | `https://api.minimax.chat/v1` |
| OpenAI | `https://api.openai.com/v1` |
| 本地模型 | Ollama / LM Studio，默认 `http://127.0.0.1:11434/v1`，密钥可留空 |
| 自定义 | 任意 OpenAI 兼容接口 |

密钥使用 Windows DPAPI 加密后存于本地（`hubai-key.bin`），不上传服务器。同一服务商可配置多条模型，各自独立保存密钥。

对话可以调用工具读取本机概况、目录占用、已安装软件、开机启动项、软件库与文档库，也可在开启联网后检索与打开网页。工具均为只读操作，不会改动系统。单次提问的回答时间上限为八分钟，超出时说明已经查到的部分，可继续追问；回答末尾会给出可直接点击的入口，涉及修改系统的操作只提供跳转，由用户自行确认。

软件下载、AppData 管理、应用卸载、PowerPoint 触控优化等页面提供提问入口，可就当前页面提问。

### 工具侧边栏

可把常用工具放进屏幕边缘的侧边栏，支持：

- **两种模式**：贴靠（只能贴左右边）与自由（四条边均可）
- **双栏**：左右两条同时显示，可分别配置
- **模块**：抽号、计时、秒表、时钟等，可勾选、排序、拖入拖出
- **密度与间距**：标准 / 紧凑，展开与收起可分别设置
- 支持置顶、贴边隐藏与展开动画

### 截屏贴图

拖拽框选屏幕区域后进入编辑：画笔、荧光笔、箭头、矩形、椭圆、文字、马赛克；支持撤销重做、复制、存盘与钉图。截屏走 Win32 GDI（`CreateDIBSection` + `BitBlt`），不依赖 `Windows.Graphics.Capture`。

### 实验性功能

以下四项位于「实验性功能」页，结果不保证准确，可通过「反馈中心」提交使用结论。

| 页面 | 能力 |
| --- | --- |
| 本机核实 | 读取「程序和功能」注册表，与软件清单做名称模糊比对；结果不保证准确 |
| 程序专杀 | 用户指定进程名，分别配置结束时间点 |
| 应用卸载 | 调用软件自带卸载器卸载，需要时提权；并提供已卸载软件的残留清理 |
| 开机启动项 | 查看 / 启用 / 禁用当前用户与所有用户的启动项（注册表 `Run` 3 处 + 启动文件夹 2 处，共 5 个位置） |

应用本体以普通用户权限运行；「所有用户」级启动项、系统修复命令、系统功能与系统优化、虚拟内存调整、卸载残留清理会通过 `runas` 启动提权助手（弹一次 UAC）。

### 授权与条款

官方发布的安装包无需激活，投稿、反馈、教室喊话等在线服务可直接使用。自行编译的版本需要使用激活码，激活后设置页显示激活时间。

条款与声明（用户协议、隐私政策、免责声明）改为在线获取，内容更新不再随版本发布；取不到网络时使用安装包内置的副本。

## 更新

1. 在设置页选择更新通道：正式版（stable）或预览版（insider）。
2. 客户端读取**本版本自己的仓库** `ClassSoftwareHub-Desktop` 的 Release：正式版取非预发布的最新版，预览版取预发布及非预发布。
3. 发现新版本后下载安装包，优先按同名 `.md5`、其次按 GitHub API 的 SHA256 校验，校验不通过不会执行安装包。当前 Win10 版在发布方未提供任何校验值时会记录警告后继续安装；如遇此类发布，建议等待补传校验值。
4. 安装过程为静默安装，许可页跳过并视为已接受。
5. 可查看历史版本并回滚，回滚不校验版本高低。

## 故障排查

| 现象 | 原因 | 处理方式 |
| --- | --- | --- |
| 双击桌面图标无反应 | 关闭窗口默认收进托盘，第二个实例被单实例互斥体拦下 | 第二个实例会通过命名事件唤醒第一个实例；也可检查托盘区（含溢出区） |
| 软件列表为空 | 首次启动未联网，或 GitHub 访问不通 | 联网后重试；若持续失败，检查 `github.com` 与 `raw.githubusercontent.com` 连通性 |
| 详情页内打开官网无反应 | 未安装 WebView2 运行时 | 安装 WebView2 Runtime（Evergreen） |
| 界面卡顿或花屏 | 显卡驱动异常，或硬件加速不可用 | 更新显卡驱动；仍异常时反馈日志 |
| 下载速度慢 | 自建加速不可用，已回退公共镜像或 GitHub 原始地址 | 稍后重试；自建加速按 IP 有限额 |
| 更新提示校验失败 | 下载不完整或发布资产异常 | 重新下载；仍失败请反馈版本号与日志 |
| Hub AI 报网络错误或 401 | 密钥无效、额度用尽，或服务商地址填写有误 | 在「设置 → Hub AI → 模型服务」中重新填写密钥并测试连接 |
| 提示需要激活 | 使用的是自行编译的版本 | 在设置页输入激活码；官方安装包不会出现该提示 |

日志位于 `%LOCALAPPDATA%\ClassSoftwareHub\logs\`，反馈时请提供最近一次启动目录中的 `app.log` 与 `crash.log`。
