> 获取网页端与桌面端产物

## 网页端

网页端为在线站点，无需下载：

| 入口 | 地址 |
| --- | --- |
| 主站 | `https://classsoftwarehub.us.ci` |
| 备用站点 | `https://classsoftwarehub.132614.xyz` |

如需离线使用，可在发布页获取单文件版本（约 2 MB，双击即可在浏览器打开，功能与在线版一致）。

## 桌面端

从 GitHub Releases 获取，两种形态任选：

| 形态 | 文件 | 说明 |
| --- | --- | --- |
| 安装版 | `ClassSoftwareHub-Setup-win7-dv<版本>.exe` | 安装包，装「启动器 + `app\` 子目录」，带开始菜单 / 桌面快捷方式与卸载项 |
| 便携版 | `ClassSoftwareHub-Portable-win7-dv<版本>.zip` | 解压即用，双击根目录的启动器运行，不写注册表 |

每个安装包都附带同名 `.md5`，下载后请校验完整性。

## 版本通道

| 通道 | tag 形态 | 说明 |
| --- | --- | --- |
| 正式版（stable） | `dv1.0.0` | 经过完整测试，推荐日常使用 |
| 预览版（insider） | `dv1.0.0-insider1.1` | 提前体验新功能；发布时勾选 Pre-release |

客户端可在设置页切换更新通道。正式版通道只接收非预发布版本，预览版通道同时接收预发布与非预发布版本。

## 系统要求

| 版本 | 系统要求 |
| --- | --- |
| Windows 7 兼容版 | Windows 7 SP1 及以上（x64） |
| WinUI 3 原版桌面端 | Windows 10 1809 及以上 |

两版安装目录与安装标识不同，可在同一台机器上共存。
