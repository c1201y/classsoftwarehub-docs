> Get the web site and desktop builds

## Web

The web site is online, no download needed:

| Entry | Address |
| --- | --- |
| Main site | `https://classsoftwarehub.us.ci` |
| Mirror | `https://classsoftwarehub.132614.xyz` |

For offline use, a single-file build (~2 MB) is available from the releases page; double-click it in a browser and it works the same as the online version.

## Desktop

Get builds from GitHub Releases, in two forms:

| Form | File | Notes |
| --- | --- | --- |
| Installer | `ClassSoftwareHub-Setup-win7-dv<version>.exe` | Installs a launcher plus an `app\` folder, with Start-menu / desktop shortcuts and an uninstall entry |
| Portable | `ClassSoftwareHub-Portable-win7-dv<version>.zip` | Unzip and run; double-click the launcher in the root; writes no registry entries |

Each package ships a matching `.md5`; verify integrity after downloading.

## Channels

| Channel | Tag form | Notes |
| --- | --- | --- |
| Stable | `dv1.0.0` | Fully tested, recommended for daily use |
| Insider | `dv1.0.0-insider1.1` | Early access to new features; published as a Pre-release |

The channel can be switched in the client settings. The stable channel receives non-prerelease versions only; the insider channel receives both prerelease and non-prerelease versions.

## System requirements

| Build | Requirement |
| --- | --- |
| Windows 7 build | Windows 7 SP1 or later (x64) |
| WinUI 3 desktop build | Windows 10 1809 or later |

The two builds use different install directories and install identities, so they can coexist on the same machine.
