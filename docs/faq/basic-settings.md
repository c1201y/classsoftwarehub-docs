> 高频基础问题速查

## 网页端打不开怎么办

依次尝试：主站 → 备用站点。若两者均无法访问，请检查本地网络或 DNS 设置。福建闽北、闽西地区用户可能遇到备用站无法打开的情况，属区域性网络问题。

## 网页端需要登录吗

不需要。网页端无账号体系，浏览、搜索、下载与全部内置工具均对访客开放。提交软件、回声洞投稿与反馈中心亦无需账号。

## 桌面端首次启动为什么是空列表

安装包不自带内容包，首次启动必须联网从 GitHub 仓库同步软件数据。未取到时界面显示「尚未获取到内容」并给出重试入口。连接网络后点击重试即可。

## 桌面端数据存放在哪里

| 内容 | 位置 |
| --- | --- |
| 数据根目录 | `%LOCALAPPDATA%\ClassSoftwareHub\` |
| 同步的软件数据 | `%LOCALAPPDATA%\ClassSoftwareHub\content\` |
| 日志 | `%LOCALAPPDATA%\ClassSoftwareHub\logs\{启动时间}\` |
| WebView2 用户数据 | `%LOCALAPPDATA%\ClassSoftwareHub\WebView2\` |

## 如何切换深色模式

桌面端在设置页「外观」中切换，支持 `system` / `light` / `dark` 三值。开启「分体外观」后，侧边栏、工具浮窗与截图编辑窗可使用独立的外观设置。

## 关闭窗口后程序还在运行吗

默认是。关闭窗口默认收进托盘而非退出进程，因此再次点击桌面图标时，第二个实例会唤醒已运行的实例并显示主窗口。如需关闭窗口即退出，可在设置中关闭「收进托盘」选项。

## 便携版和安装版有什么区别

| 对比项 | 安装版 | 便携版 |
| --- | --- | --- |
| 安装方式 | 运行安装程序 | 解压即用 |
| 快捷方式 | 开始菜单 / 桌面 | 无，双击根目录 exe |
| 卸载项 | 有 | 无，直接删除目录 |
| 注册表 | 写入 | 不写 |
| 自动更新 | 支持 | 不支持自动替换自身，需手动替换 `app\` 文件夹 |
| 结构 | 启动器 + `app\` | 启动器 + `app\`（同构） |

## 两个桌面版本能同时装吗

能。Windows 7 兼容版与 WinUI 3 原版的安装目录（`...\Programs\ClassSoftwareHub-Win7`）与安装标识均不同，不会互相覆盖，也不会收到对方的更新。

## 更新一直失败怎么办

1. 确认更新通道设置是否正确（正式版通道收不到预览版）。
2. 确认网络可访问 `github.com`。
3. 若提示校验失败，请重新下载；若提示缺少校验值，说明该发布未提供 `.md5` 资产，属预期的安全中止。
4. 查看日志中 `update` 模块的链路记录。
