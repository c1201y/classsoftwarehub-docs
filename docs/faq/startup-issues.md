> 启动失败、安装异常与渲染问题的排查

## 双击桌面图标没反应

**现象**：点击桌面图标后无任何窗口出现，多次点击仍无界面。

**原因**：关闭窗口默认收进托盘，进程并未退出；第二个实例被单实例互斥体拦下，而第一个实例未能亮出主窗口。

**处理方式**：查看托盘区（含溢出区）是否有应用图标并点击。若仍无反应，以 `--takeover` 参数启动一次，该参数会在单实例冲突时直接结束拿不出可见主窗口的现有实例。

## 安装程序提示系统不满足要求

**现象**：运行安装程序时提示系统版本过低并终止安装。

**原因**：低于 Windows 7 SP1。.NET 6 在 Windows 7 上要求 SP1，这是硬门槛。

**处理方式**：安装 Windows 7 Service Pack 1 后重试；或改用网页版，功能一致且不受系统版本限制。

## 安装过程中提示应用正在运行

**现象**：安装过程中弹出对话框提示应用正在运行。

**原因**：旧版本进程未退出（关闭窗口默认收进托盘）。

**处理方式**：按提示确认即可。安装程序会先礼貌关闭（`taskkill`），不退再强杀；应用无未保存状态、设置即时落盘，被杀不丢数据，安装完成后会自动拉起应用。

## 安装后桌面没有快捷方式

**现象**：安装完成后桌面没有应用图标。

**原因**：安装时取消了「创建桌面快捷方式」任务；或在升级场景中，用户此前已删除桌面图标，安装程序按现状保留而不会强行建回。

**处理方式**：重新运行安装程序并勾选「创建桌面快捷方式」任务；或从开始菜单手动创建。

## 启动后界面花屏或不出

**现象**：启动后主界面花屏、出现色块，或完全不显示。

**原因**：显卡驱动不兼容 D3D11 / OpenGL，自动降级链也救不回来。

**处理方式**：以 `--software-render` 参数启动，强制走软件渲染。界面会慢一点，但至少能出来。该参数正式版同样识别。

## 界面出现随机灰矩形残影

**现象**：抽号页等动画密集页面出现位置随机的浅灰矩形残影，每帧形状不同。

**原因**：Windows 7 老显卡的表面保帧不可靠，局部重绘时未重绘区域露出残留像素。

**处理方式**：Windows 7 上默认已启用软件渲染，该问题从机制上不可能出现。如仍出现，显式加 `--software-render` 参数启动。

## 启动很慢

**现象**：从启动到主窗口露脸需要数秒。

**原因**：.NET 运行时加载与程序集 JIT 开销占大头。实测进程启动到主窗口露脸约 6.4s，其中约 4.4s 花在运行时加载与 JIT 上。

**处理方式**：属预期。发布产物已启用 ReadyToRun 预编译以缩短这一段。老机器上可进一步关闭不必要的开机启动项。

## 排查用的命令行开关

| 开关 | 作用 |
| --- | --- |
| `--software-render` | 强制软件渲染 |
| `--gpu-render` | 放行 GPU 渲染降级链 |
| `--takeover` | 单实例冲突时直接结束拿不出可见主窗口的实例 |
| `--simulate-win7` | 强制按 Windows 7 分支运行（开发机用） |
